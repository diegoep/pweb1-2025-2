Boas Práticas Mobile First

Como estruturar CSS para responsividade

1. Comece Mobile

/* CSS base para mobile */
.container {
  display: flex;
  flex-direction: column;
}

2. Adicione Media Queries

/* Para tablet em diante */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

3. Teste em Múltiplos Dispositivos

  • DevTools - Device Simulation
  • Navegadores reais
  • Testar velocidade (throttling)
