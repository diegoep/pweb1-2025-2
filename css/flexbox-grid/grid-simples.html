HTML:

<div class="gallery">
  <div class="gallery-item">🖼️</div>
  <div class="gallery-item">🖼️</div>
  <div class="gallery-item">🖼️</div>
  <!-- mais itens -->
</div>

CSS:

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 15px;
}
💡 Conceitos:
  • display: grid - Ativa CSS Grid
  • repeat(auto-fit, ...) - Repete colunas quantas couberem
  • minmax(200px, 1fr) - Mínimo de 200px, máximo flexível
  • gap: 15px - Espaço entre itens
📱 Responsividade Automática:
  • Desktop (1920px): 9 imagens por linha
  • Tablet (768px): 3 imagens por linha
  • Mobile (360px): 1 imagem por linha
  • ✨ Tudo sem media queries!
