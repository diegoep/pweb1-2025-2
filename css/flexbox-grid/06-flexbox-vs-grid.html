⚖️ Flexbox vs Grid

Entenda quando usar cada um

📐 Número de Dimensões

📏 Flexbox

Flexbox trabalha em uma dimensão apenas.

Apenas linha:

A
B
C

Se você quer uma linha ou uma coluna — Flexbox!

📐 Grid

Grid trabalha em duas dimensões (linhas E colunas).

Linhas e colunas:

A
B
C
D

Se você quer linhas E colunas — Grid!

🎯 Casos de Uso

Flexbox é Melhor Para:

  • ✓ Navegações e menus
  • ✓ Botões agrupados
  • ✓ Cards em linha
  • ✓ Centering e alinhamento
  • ✓ Componentes pequenos
  • ✓ Distribuição de espaço

Grid é Melhor Para:

  • ✓ Layouts de página
  • ✓ Dashboards
  • ✓ Galerias de fotos
  • ✓ Posicionamento preciso
  • ✓ Estruturas complexas
  • ✓ Layouts 2D (linhas + colunas)
⚙️ Propriedades Principais

Flexbox

  • display: flex
  • flex-direction: row | column
  • justify-content - eixo principal
  • align-items - eixo secundário
  • flex-wrap: wrap
  • gap: 20px
  • flex-grow, flex-shrink, flex-basis

Grid

  • display: grid
  • grid-template-columns
  • grid-template-rows
  • gap - linhas e colunas
  • grid-column: span 2
  • grid-row: span 3
  • justify-content, align-content
💻 Sintaxe

Flexbox

CSS
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 20px;
}

.item {
  flex: 1;
}

Grid

CSS
.container {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
  gap: 20px;
}

.item:first-child {
  grid-column: span 2;
}

🚀 Exemplos Práticos

Navegação

Use Flexbox 

<nav class="navbar">
  <div class="logo">Logo</div>
  <ul class="nav-menu">
    <li><a href="#">Home</a></li>
  </ul>
</nav>

.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

Dashboard

Use Grid 

.layout {
  display: grid;
  grid-template-columns:
    250px 1fr;
  grid-template-rows:
    auto 1fr;
}

header {
  grid-column: 1 / -1;
}

Cards

Use Grid Responsivo 

.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(250px, 1fr));
  gap: 20px;
}

Header + Sidebar + Main

Use Grid (2D) 

.layout {
  display: grid;
  grid-template-columns:
    200px 1fr;
  grid-template-areas:
    "header header"
    "sidebar main";
}

Menu Horizontal

Use Flexbox 

.menu {
  display: flex;
  gap: 15px;
  justify-content: center;
}

.menu-item {
  flex: 1;
}

Galeria 2D

Use Grid 

.gallery {
  display: grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(150px, 1fr));
  grid-template-rows:
    repeat(auto-fit,
      150px);
}

✨ Resumo: Quando Usar

🎯 Use Flexbox Quando:

  • Você quer alinhar itens em uma linha ou coluna
  • Precisa de distribuição automática de espaço
  • Quer reordenar itens visualmente
  • Construindo componentes pequenos
  • Precisa de wrap automático em telas pequenas

📐 Use Grid Quando:

  • Você quer alinhar em linhas E colunas
  • Precisa de posicionamento preciso
  • Construindo layouts de página
  • Criando dashboards ou galerias
  • Quer responsividade automática com auto-fit
💡 Pro Tip:

Você pode combinar os dois! Use Grid para o layout da página e Flexbox para os componentes dentro. Eles trabalham bem juntos.
