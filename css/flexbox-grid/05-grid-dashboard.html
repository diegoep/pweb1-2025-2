💡 Grid Structure

Este dashboard usa CSS Grid para criar um layout responsivo. A estrutura: 

.layout {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-rows: auto 1fr;
  gap: 20px;
}

/* Header em toda a largura */
header {
  grid-column: 1 / -1;
}

/* Sidebar fixa */
aside {
  grid-column: 1;
  grid-row: 2;
}

/* Main com grid responsivo */
main {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
}

/* Card largo */
.card.wide {
  grid-column: span 2;
}

📐 Como Este Layout Funciona

O dashboard acima demonstra um uso prático de CSS Grid. A página usa:

  • Grid externo: Layout de 2 colunas (sidebar + main)
  • Header: Ocupa ambas as colunas com grid-column: 1 / -1
  • Sidebar: Largura fixa de 250px
  • Main: Outro grid responsivo com repeat(auto-fit, minmax(300px, 1fr))
  • Cards: Se adaptam automaticamente ao tamanho da tela
  • Wide cards: Ocupam 2 colunas com grid-column: span 2

✨ Vantagens Este Design

  • ✅ Totalmente responsivo sem media queries complexas
  • ✅ Sidebar fixa, conteúdo fluido
  • ✅ Cards se reorganizam conforme o espaço
  • ✅ Mantém proporções em qualquer dispositivo
  • ✅ Fácil de manter e modificar
